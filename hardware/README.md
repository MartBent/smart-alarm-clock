which gates committing to a PCB.

- KiCad schematic + 2-layer PCB layout (ESP32-S3-WROOM-1 reference → custom board)
- Gerbers / fab outputs
- Enclosure: the wood-veneer bar (models, veneer notes)

Design rationale and the locked hardware decisions live in
[`../docs/handoff.md`](../docs/handoff.md).
